## 任务组合与完整性

- 制定个人计划：资金规划 → 组合风险 → ETF 或个股研究；画像和持仓分别读取，缺少事实先询问。
- 设计量化策略：策略设计 → 回测验证 → 市场规则；未实测时只交付研究方案。
- 比较两只 ETF：ETF 研究 → 组合风险；获取同日/同口径数据，再判断是否重复持仓。
- 复盘过去的决策：策略设计 → 回测验证 → 当时适用的规则；不能把今天的知识伪装为当时已知信息。
- 查询最新价格：直接调用金融工具，无需先读整个知识库。

命中一个专题不代表已经覆盖全部风险。资料不够时沿文末相关链接补读；全市场排名、统计和历史收益必须查询完整结构化数据并由代码计算，不能由检索片段外推。

## 来源、时效和边界

[来源登记](sources.md)包含 18 项外部来源的链接、定位、短摘录、适用范围和核验限制。优先使用交易所、监管机构、专业协会与工具作者的资料；不收录论坛收益截图或无法核实的“稳赚参数”。国外资料只借鉴通用研究方法，不将其税制、交易单位或账户规则套到 A 股。

专题中区分：**来源知识**（有外部依据）、**项目应用建议**（结合项目约束的设计）、**待验证假设**（需要真实数据检验）。所有示例参数和公式都不是当前行情或已确认用户数据。数值计算交给工具/代码。

`verified_at` 只表示此次核验日期，不保证此后仍有效。交易制度、税费、产品合同、基金规模与成分应在实际使用时重新核验。冲突必须按地区、证券类型、日期和规则层级解释，不按网页“更新较新”直接覆盖。

## 接入方式与维护

L0：启动时从 `knowledge/topics/*.md` 的 frontmatter 自动生成专题目录，包含用途、路径、版本、核验日期和复核日期，直接进入系统静态前缀；L1：本页问题索引，阅读路径不明确时使用；L2：通过 `read` 按需获取专题全文及来源证据。模型无需先打开 Skill 才能发现知识库，也不会自动注入全库。当前没有向量索引、全文搜索工具或自动刷新任务。

系统提示词要求相关研究主动查阅、跨专题补读，并允许复用当前上下文中仍有效的完整资料。问候、单纯报价及机械筛选不强制读取；读取失败或资料不足须明确报告。该策略仍由模型执行，不是编排层的强制证据门控。新增专题须提供合法的 `id`、`scope`、`version`、`verified_at`、`review_after` 单行元数据；无效元数据会在启动时明确报错。重启后更新目录，不在每轮重建静态前缀。

遵循参考书第 03 章的文件系统组织、交叉链接、知识与用户记忆隔离、来源核查及可回滚更新思路。具体取舍见[维护规范](maintenance.md)，行为验收题见[评估清单](evaluation.md)。文件只保存共享知识，禁止写入用户资产、身份或密钥。

当前为本地整理版本，未经独立 Reviewer 审核，不标记为生产已批准知识。实时 API、回测引擎与执行风险约束是否可用，仍以当前工具和代码为准。
