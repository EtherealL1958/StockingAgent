# 策略设计：让想法可以被检验和推翻

摘要：策略需要经济解释、结构化规则、执行条件、风险边界和反证。策略描述、历史回测、样本外验证和真实执行是不同证据等级。

## 来源知识

因子指数刻画价值、质量、动量、波动、规模等风格暴露；因子名称不说明它在所有市场和时期有效。[S13](../sources.md#s13)

指数增强以基准为参照，并约束跟踪风险；排序、因子合成和组合构建是不同环节。因子可用 IC、分组表现等检验，不能只凭一张综合得分表认定有效。[S09](../sources.md#s09)

回测应先明确投资假设与目标，再确定规则、构建组合并衡量风险收益。[S10](../sources.md#s10)

## 项目应用建议：策略卡

| 字段 | 应写清的内容 |
| --- | --- |
| 标识与状态 | 名称、版本、建立日期；`HYPOTHESIS` / `BACKTESTED` / `OUT_OF_SAMPLE_TESTED` |
| 投资假设 | 为什么可能获得补偿或降低风险；哪些观察会推翻它 |
| 适用用户 | 投资期限、资金下限、可承受波动；来自确认画像 |
| 标的范围 | 证券类型、板块、历史入选规则、上市/退市处理 |
| 数据 | 字段、报告期、可见时间、复权口径、缺失处理 |
| 信号 | 因子定义、方向、窗口、计算频率、阈值；不能只写“趋势好” |
| 组合 | 权重生成方法、整手取整、现金余额、相关性与集中度 |
| 交易 | 信号产生时间、最早可成交时间、费用、滑点、无法成交的处理 |
| 退出与失效 | 业务逻辑失效、风险超限、期限到期、数据质量问题分别定义 |
| 验证 | 基准、训练/验证/测试区间、参数尝试记录、压力情景 |
| 维护 | 检查周期、触发重评条件、负责人/用户确认及版本变更原因 |

这些字段是项目研究模板，尚不是已执行的策略，也不表示当前全部工具已实现。

## 候选研究方向与反证

以下为待验证假设，不是推荐名单或有效性结论：

| 研究方向 | 可检验的问题 | 容易失败的情形 |
| --- | --- | --- |
| 宽基 ETF + 现金 + 定期复核 | 能否在用户期限内取得可承受的权益暴露？ | 权益整体下跌、短期要用钱；分散不能消除市场风险 |
| 质量与估值联合筛选 | 同行业内经营质量与价格是否同时合理？ | 一次性利润、会计失真、价值陷阱、长期风格逆风 |
| 红利/低波动暴露 | 扣费后能否改善风险收益，而非只是改变行业权重？ | 分红削减、行业集中、历史低波动失效 |
| 低频趋势/动量过滤 | 是否在不同窗口减少尾部风险？ | 震荡反复交易、趋势反转、跳空导致滞后 |
| 再平衡 | 是否在相同资金流下控制偏离和风险？ | 成本过高、资产基本假设已失效却机械补仓 |

定投属于投入节奏，不能独立证明选中资产值得长期持有。[S04](../sources.md#s04)

## 从评分到组合

质量、估值、稳定性等分项须统一方向、样本范围、单位和可见时间；缺失数据保持缺失，并披露排序覆盖率。标准化与阈值属于研究设定，不能在全部历史上挑选后再宣称样本外效果。

项目现有评分权重是可解释的偏好设定，不是已校准的收益预测。高分不意味着买得起、适合当前组合或上涨概率高。依次检查画像适配、数据充分性、执行数量、费用与硬约束；任何关键条件缺失时可停留在观察名单或 `NO_TRADE`。

## 预测与复盘

优先预测趋势状态、波动状态或相对强弱。数值预测需保存预测时点、期限、特征窗口、训练范围、模型版本和样本外指标。未经校准的模型置信度不能表述为上涨概率。

复盘分开记录：判断是否有当时证据、执行是否遵守规则、结果是否受市场暴露驱动。一次赚钱不升级为普遍经验，一次亏损也不自动证明假设失效；用预先定义的观察项重新检验。
