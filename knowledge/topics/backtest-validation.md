# 回测验证：先排除虚假的优势

摘要：正确的回测模拟当时的信息与交易条件；好看的历史收益不能替代样本外验证。没有数据、代码和运行记录时，不输出回测数字。

## 来源知识

财报应按真实可见时间使用；当前成分股回测过去会漏掉已退出的证券，修订后的财务数据也可能泄漏未来信息。[S11](../sources.md#s11)

时序验证按过去训练、未来测试排列；随机切分可能造成时间倒置。`TimeSeriesSplit.gap` 用于在训练尾部和测试前留出样本间隔。[S12](../sources.md#s12)

历史回测应补充压力情景和敏感性分析；有限历史未必覆盖未来分布和极端风险。[S10](../sources.md#s10)

## 项目应用建议：先冻结实验

在观察结果前保存策略版本、数据版本、基准、参数范围、资金流、费用、执行时点和评估区间。记录尝试过的变体与失败结果，不能只保存最佳曲线。

数据检查至少包括：

| 检查 | 失败例子 | 应如何处理 |
| --- | --- | --- |
| 财报时间 | 把 12 月末报告期当成公告可见日期 | 查实际披露时间；未知时标记无法可靠回测 |
| 成分与存续 | 用今天的指数成分回测十年前 | 获取当时成分及退市数据；否则披露样本偏差 |
| 复权与价格 | 用今天前复权的历史低价判断当时买得起 | 收益与交易价格用途分开，保存复权因子时间口径 |
| 数据预处理 | 在全样本拟合标准化、填充或选择因子 | 只在训练期拟合，并固定应用于后续区间 |
| 信号与成交 | 用收盘后才确定的信号按同日收盘价无条件成交 | 使用下一可交易时点，或证明信号与订单当时可用 |
| 标签重叠 | 训练标签使用了测试期未来收益 | 按实际标签结束时间排除重叠，不能只机械留一行 gap |

面板数据应按完整交易日期分组，避免同一天的不同股票跨越训练和测试边界。停牌和缺失日不能用未来价格填充。

## 验证层次

1. 训练期：选择有限的因子与参数，解释经济含义。
2. 验证期：比较少量候选，记录选择依据；参与选择后它就不是最终测试集。
3. 保留测试期：固定规则后运行；如果依据结果修改策略，应重新标记并设置新的未触碰区间。
4. 滚动前推：在每个窗口只使用当时可用信息重新估计，拼接真实样本外片段。
5. 稳健性：改变起止日、参数邻域、交易延迟、成本假设和市场阶段；孤立最优点应降低可信度。

## A 股执行模拟

按[市场规则](market-rules.md)核验当期最小数量、可卖数量、停牌、涨跌幅限制与价格精度。涨跌停且日线显示有成交量，也不能证明自己的订单能够成交；没有盘口时应采用明确保守假设并报告局限。

逐笔记录：信号时间、订单时间、成交/拒绝原因、数量、价格、费用、剩余现金。整数数量与最低费用必须进入现金检查；不能最后简单对理论收益扣一个固定百分比。

## 必须交付的结果

基础结果包含净收益、最大回撤、基准收益、交易次数和净值曲线；补充换手、费用占比、波动、风险暴露、回撤持续时间及失败订单。报告金额口径、收益口径、分红处理、样本量和缺失覆盖率。

有外部资金流时，不能把“期末资产减期初资产”直接叫策略收益；比较双方使用相同投入/提款时间，说明时间加权或资金加权口径。基准须与研究目标相符，不能拿高权益暴露策略与纯现金比较后宣称选股能力。

“未检验”“数据不支持”“成本后没有优势”都是合格研究结论。历史最大回撤不是未来最大损失保证。
