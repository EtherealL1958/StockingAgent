# A 股技术分析规范

## 什么时候使用

当用户询问“走势、趋势、强弱、波动、回撤、是否适合观察”时使用 `get_market_history`。需要逐根日线时明确传 `includeBars=true`。

若要将指标转成策略，按需读取 [策略设计](../../knowledge/topics/strategy-design.md) 与 [回测验证](../../knowledge/topics/backtest-validation.md)；这些知识不能证明指标在当前市场有效。

## 指标解释

- 趋势：比较 MA20、MA60、MA120 与最新收盘价，说明趋势方向和可能的震荡状态。
- 风险：优先报告年化波动率、最大回撤、回撤持续时间和停牌情况。
- 动量：可报告 RSI14、区间收益和成交量变化，但动量权重不能高于基本面与风险。
- 对比：尽量与相关宽基指数或行业指数比较，避免把大盘涨跌误认为个股能力。

## 边界

- MA、EMA、MACD、RSI、ATR、波动率和回撤必须使用工具或 domain 代码的结果，不由模型手算。
- 指标是证据，不是自动交易规则；单一指标不能产生买入或卖出结论。
- 数据窗口不足时明确写“指标不可用”或“样本不足”，不能补齐历史数据。

## 输出结构

按“趋势状态 → 风险状态 → 相对表现 → 反转条件 → 个人投资者行动”输出。行动可以是继续观察、分批研究、降低仓位或 `NO_TRADE`。
