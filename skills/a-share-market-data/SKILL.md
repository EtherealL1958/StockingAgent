# A 股行情数据规范

## 什么时候使用

当用户询问最新价格、历史走势、成交量、指数或 ETF，或者准备基于行情做任何判断时使用。先调用 `get_quote` 或 `get_market_history`，不要凭记忆填写价格。

交易规则或历史数据口径不清时读取 [市场规则](../../knowledge/topics/market-rules.md)；ETF 专项比较读取 [ETF 研究](../../knowledge/topics/etf-research.md)。引用知识时检查适用日期，不能以旧投教文档代替当期规则。

## 数据流程

1. 将用户给出的证券名称解析为唯一的六位数字代码；代码不确定时先询问或使用可验证的基础信息。
2. 记录 `requestedInstrument`、`normalizedInstrument`、`source`、`asOf`、起止日期、复权口径和返回条数。
3. 将实时快照、历史日线、指数数据和财务报告期分开描述。
4. `barCount=0`、报价缺失、停牌或 Provider 错误必须标记为数据不可用或分析不完整，不能当作零收益或利空。

## 边界

- `get_quote` 只返回快照，不代表买入建议，也不能替代历史序列。
- `get_market_history` 的摘要指标由程序计算；不要让模型根据截断后的日线重新计算完整指标。
- `screen_stocks` 返回的是扫描范围内的候选，不是全市场排名；必须报告 `scannedCount` 和排除统计。
- 网页搜索可以补充公告或新闻，但不能替代同花顺行情和财务数据。

## 输出示例

“截至 2026-10-05，数据源为同花顺，600519 返回 238 根日线；以下收益和回撤基于该窗口计算。财务报告期为 2025-4，未提供的数据保持缺失。”
