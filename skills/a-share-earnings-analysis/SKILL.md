# A 股财报分析规范

## 什么时候使用

当用户要求查询年报、季报、营收、利润、ROE、现金流、负债或经营质量时使用。调用 `get_fundamentals` 时必须显式传入报告期，例如 `report=2025-4`。

## 分析顺序

1. 先列出公司、报告期、数据源和可用字段。
2. 再描述营收、净利润、ROE、毛利率、经营现金流、自由现金流和负债率的变化。
3. 计算同比或趋势时说明比较期；缺少比较期时只陈述当前值。
4. 将盈利质量、现金流质量、杠杆和估值风险分别说明。

## 边界

- 当前工具返回的是标准化财务指标，不等同于完整利润表、资产负债表或现金流量表。
- 缺失字段不能当作零，也不能据此判断公司没有该项业务。
- 单个季度或单个指标不能决定公司价值；应结合行业、估值和行情风险。
- 财报发布日期未知时，不得在回测或历史复盘中使用未来可见数据。

## 输出示例

“2025 年年报显示营收同比增长 X，ROE 为 Y；经营现金流字段缺失，因此现金流质量无法完整判断。上述内容是财报事实，‘盈利稳定性一般’属于基于多项证据的解释。”
